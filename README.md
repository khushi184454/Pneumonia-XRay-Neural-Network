# Pneumonia Detection Using Chest X-Ray Images

## Project Description

This project focuses on exploratory data analysis and preprocessing of chest X-ray images for pneumonia detection. The dataset contains two classes: NORMAL and PNEUMONIA.

## Dataset

Chest X-Ray Images (Pneumonia) dataset.

The dataset is used for educational and research purposes.

## Tools and Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Pillow
- OpenCV
- Scikit-learn
- TensorFlow
- Keras

## Exploratory Data Analysis

The analysis includes:

- Dataset structure
- Missing values
- Duplicate images
- Corrupt image checking
- Class distribution
- Sample X-ray visualization
- Image dimensions
- Pixel intensity distribution
- Mean image analysis
- Patient-level leakage checking

## Future Work

A CNN-based neural network will be developed to classify chest X-ray images as NORMAL or PNEUMONIA.
